# businessbrokerage.eu

Static reference site on business brokerage in Europe, generated with Python without external packages.

    python3 build.py     # writes dist/
    python3 check.py     # links, anchors, register, duplicates, sitemap

- `core.py` page shell, layout and sitemap
- `art.py` schematic line drawings in SVG
- `content_handbook.py` twelve chapters
- `content_methods.py` five valuation methods
- `content_markets.py` eight country notes
- `content_glossary.py` glossary terms
